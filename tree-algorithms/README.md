# 二叉树遍历算法

本文件夹包含了二叉树的各种遍历算法实现，包括递归和迭代两种方式。

## 文件结构

- `binary_tree_traversal.go` - 主要算法实现
- `binary_tree_traversal_test.go` - 单元测试
- `demo.go` - 演示程序
- `README.md` - 说明文档

## 算法概述

### 1. 前序遍历 (Preorder Traversal)
- **顺序**: 根 → 左 → 右
- **应用**: 复制树、前缀表达式
- **时间复杂度**: O(n)
- **空间复杂度**: O(h) - h为树的高度

### 2. 中序遍历 (Inorder Traversal)
- **顺序**: 左 → 根 → 右
- **应用**: 二叉搜索树的有序输出
- **时间复杂度**: O(n)
- **空间复杂度**: O(h) - h为树的高度

### 3. 后序遍历 (Postorder Traversal)
- **顺序**: 左 → 右 → 根
- **应用**: 删除树、后缀表达式、计算目录大小
- **时间复杂度**: O(n)
- **空间复杂度**: O(h) - h为树的高度

### 4. 层序遍历 (Level Order Traversal)
- **顺序**: 按层从左到右
- **应用**: 广度优先搜索、打印树的层级结构
- **时间复杂度**: O(n)
- **空间复杂度**: O(w) - w为树的最大宽度

## 实现方式

每种遍历都提供了两种实现：

1. **递归实现**: 代码简洁，易于理解
2. **迭代实现**: 使用栈或队列，避免递归调用栈溢出

## 示例树结构

```
       1
      / \
     2   3
    / \
   4   5
```

## 遍历结果

- **前序遍历**: [1, 2, 4, 5, 3]
- **中序遍历**: [4, 2, 5, 1, 3]
- **后序遍历**: [4, 5, 2, 3, 1]
- **层序遍历**: [[1], [2, 3], [4, 5]]

## 性能对比

基于基准测试结果（在Intel i5-7360U上测试）：

| 算法 | 实现方式 | 性能 (ns/op) | 内存分配 (B/op) | 分配次数 |
|------|----------|--------------|----------------|----------|
| 前序遍历 | 递归 | ~159 | 120 | 4 |
| 前序遍历 | 迭代 | ~368 | 344 | 7 |
| 中序遍历 | 递归 | ~164 | 120 | 4 |
| 中序遍历 | 迭代 | ~342 | 344 | 7 |
| 后序遍历 | 递归 | ~160 | 120 | 4 |
| 后序遍历 | 迭代 | ~339 | 344 | 7 |
| 层序遍历 | 迭代 | ~564 | 376 | 14 |

**结论**: 递归实现在性能和内存使用上都优于迭代实现，但迭代实现可以避免栈溢出问题。

## 关键点

1. **递归边界**: 当节点为空时返回
2. **迭代实现**: 
   - 前序和中序使用栈
   - 层序使用队列
   - 后序可以用两个栈或反向插入
3. **空间优化**: Morris遍历可以实现O(1)空间复杂度
4. **实际应用**: 不同遍历适用于不同场景
